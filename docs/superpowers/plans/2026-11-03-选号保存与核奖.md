# 选号保存与核奖 Implementation Plan

**Goal:** 保存生成号码并在同步后按目标期官方开奖核对，中奖时播放五秒庆祝动画和音效。

**Architecture:** SQLite 记录基准期、候选号码、生成时间、核对状态和通知状态；核对时从官方接口确认下一期确实紧接基准期，并从官方公告确认福运奖。Qt 动画层独立绘制半透明遮罩和下落元宝，使用本地音效播放。

**验证步骤:**
1. 测试六个常规奖级优先顺序、福运奖状态未知、号码保存及跨期核对，然后实现。
2. 测试同期重复同步、断网、缺期与重复通知，然后接入同步后台流程。
3. 测试动画五秒结束及历史记录界面，检查真实桌面效果。
4. 运行所有测试、编译、隔离打包，验证真实应用窗口；模型密钥和设备声音不能假设可用。
