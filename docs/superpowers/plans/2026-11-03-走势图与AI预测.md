# 走势图与 AI 预测 Implementation Plan

**Goal:** 将新浪双色球走势类别对应到本地可验证图表，并让模型基于结构化数据提供合法候选号码。

**Architecture:** `lottery/trends.py` 负责统计、遗漏和图表数据；`lottery/trend_ui.py` 使用 Qt 表格和高亮展示多类走势；`lottery/ai.py` 验证模型输出；`lottery/ui.py` 连接页面、范围和后台请求。

**Tech Stack:** Python、PySide6、SQLite、requests、pytest、PyInstaller。

1. 写包含连号、重号、和值、AC、奇偶、质合、三区、012 路、遗漏、缺期和窗口边界的可核验测试，确认失败后实现趋势计算。
2. 写合法、非法和代码围栏 JSON 的模型响应测试，确认失败后实现模型系统提示词与响应校验。
3. 写界面范围切换与图表、数据摘要的交互测试，确认失败后接入桌面页面和模型输入。
4. 用已保存的官方数据与新浪公开同期数字核对；执行全部测试、编译及 Windows 单文件构建，检查真实主窗口和功能。
