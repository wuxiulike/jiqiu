# 今日选号交互 Implementation Plan

**Goal:** 以首页的 1–5 注滑杆、动态球和滚动对话框串起本地选号与模型修正。

**Architecture:** `today_ui.py` 负责选号动画和状态显示；`ui.py` 调度本地算法与后台模型；`ai.py` 处理流式响应及校验。保留历史、走势图和模型设置。

**Tech Stack:** Python、PySide6、requests、pytest、PyInstaller。

1. 先测试流式输出、部分数据和模型出错，确认失败后实现 OpenAI 协议流式读取。
2. 先测试滑杆、问号球、滚动范围、模型成功和失败状态，再实现首页交互。
3. 验证模型收到的是同一批本地候选号及真实历史；检查界面动态和失败提示。
4. 运行全量测试与编译，使用隔离路径打包新的 Windows 单文件，验证实际界面。
