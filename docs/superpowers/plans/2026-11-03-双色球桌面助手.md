# 双色球桌面助手 Implementation Plan

**Goal:** 创建 Windows / macOS 桌面程序，提供官方历史开奖同步、统计选号、回测和可选 AI 解读。

**Architecture:** 数据层负责验证、SQLite、分页同步和 CSV 导入；算法层负责统计、选号和按时间滚动的回测；模型层负责 OpenAI 兼容接口与安全凭据；Qt 界面负责后台任务和交互。

**Tech Stack:** Python、PySide6、SQLite、requests、keyring、pytest、PyInstaller。

1. 为数据解析、分页同步和断点恢复先写测试，运行确认失败，再实现并验证。
2. 为选号合法性、回测时间边界和随机基准先写测试，运行确认失败，再实现并验证。
3. 为模型请求、响应解析和错误路径先写测试，运行确认失败，再实现并验证。
4. 实现桌面界面与后台工作线程，验证启动、交互、离线和同步状态。
5. 运行全部测试、编译与 Windows 打包；记录实际数据覆盖范围和 macOS 未验证情况。
